# Strand编织模式（Strand Weave Pattern）

Strand（故事线/叙事线）的规划设计方法。

---

## 一、Strand类型

| Strand类型 | 说明 | 贯穿度 |
|-----------|------|--------|
| 主线（A线） | 核心冲突、主角主要目标 | 全书 |
| 感情线（B线） | 主角与他人的情感发展 | 全书或多卷 |
| 势力线（C线） | 各势力的动向和博弈 | 多卷或单卷 |
| 成长线（D线） | 主角能力/性格的成长 | 全书 |
| 伏笔线（E线） | 埋设→发展的长期悬念 | 多卷 |

---

## 二、Strand交织原则

### 密度控制
- 每章至少涉及 2-3 条 Strand
- 不能连续 3 章只有 A 线
- B/C/D 线交替作为章节的次要线索

### 主次分配
```
全书层面：
A线（主线）：60%
B线（感情）：20%
C线（势力）：10%
D线（成长）：5%
E线（伏笔）：5%
```

### 节奏配合
```
高潮时：A线为主，其他线暂停或辅助
过渡时：B/C/D线推进，A线暂缓
铺垫时：E线埋设，其他线正常推进
```

---

## 三、Strand交织示例

### 20章卷的Strand分布
```
第1-3章：A线启动 + B线初见 + E线埋设
第4-6章：A线推进 + C线浮现
第7-9章：A线小高潮 + B线升温 + D线成长
第10-12章：A线危机 + C线变局 + E线发展
第13-15章：A线低谷 + B线转折 + D线瓶颈
第16-18章：A线反击 + C线收束 + B线确定
第19-20章：A线高潮 + 所有Strand收束
```

## 四、Strand检查

- [ ] 每条 Strand 的起止点清晰
- [ ] Strand 间的交织位置有标记
- [ ] 没有 Strand 被遗忘超过 10 章
- [ ] 每条 Strand 的收束方式已规划
