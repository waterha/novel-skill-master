# 灵感收集库（Inspiration Collection）

从各类来源系统化收集和整理创作灵感的工具。

---

## 一、灵感来源渠道

### 1. 阅读拆解
读同类作品时记录：
- 吸引你的设定/情节/人物
- 觉得可以改进的地方
- 想尝试的写法

### 2. 现实观察
- 新闻事件中的戏剧性元素
- 身边人的性格和故事
- 特定行业的冷知识和细节
- 旅行中看到的风景和文化

### 3. 跨领域联想
- 科学理论 → 小说设定（如量子力学→多重宇宙）
- 历史事件 → 故事框架（如某次真实战役→战争线）
- 其他艺术 → 叙事手法（如电影蒙太奇→场景跳转）

### 4. 创意组合（A+B）
将两个看似无关的概念组合：
```
侦探 + 魔法 = 魔法推理
餐厅 + 修仙 = 食修流
快递 + 末世 = 末世快递员
直播 + 星际 = 星际直播
```

---

## 二、灵感记录格式

### 灵感卡片
```yaml
标题：<吸引人的一句话>
类型：设定/情节/人物/世界观
来源：<哪里来的>
核心创意：<100字内描述>
可能的用法：<可用于什么题材/什么阶段>
灵感质量：⭐⭐⭐（1-5星）
```

### 灵感池管理
- 所有灵感存入 `灵感池.md`
- 按质量排序，高星优先使用
- 定期清理低质量或过时的灵感
- 已使用的灵感标注"已使用"并附上作品名
