# 🏗️ novel-settings — 角色与世界观深度构建

## 概述
完成所有核心设定的设计，包含角色、世界观、力量体系、势力格局、金手指等。设计哲学是"先深度后广度"——每个设定维度都要有可贯穿全文的内在逻辑。

## 所属阶段
第二阶段：核心设定

## 输入
- 选题策划书（来自 novel-topic）
- 可复用设定模板（character-design.md, power-systems.md 等）

## 核心流程

### 一、角色设计（6层深度）

#### Layer 1：主角欲望与缺陷
| 维度 | 要求 | 示例 |
|------|------|------|
| 表层欲望 | 前 10 章可达成的小目标 | 赚钱还债、通过考试 |
| 深层欲望 | 贯穿全文的核心驱动力 | 证明自己、找回记忆 |
| 性格缺陷 | 必须影响关键决策的致命弱点 | 过度信任、暴怒、自卑 |
| 成长弧线 | 从缺陷→克服→升华的三段路径 | 自卑→自信→谦逊 |

#### Layer 2：主角能力结构
- **天赋硬能力**：天生的特殊能力或资质
- **后天习得**：通过努力获得的技能
- **隐藏潜力**：后期觉醒的能力（预留成长空间）
- **能力边界**：明确不能做什么（防止能力膨胀）
- **能力进化表**：每 50 章一个能力里程碑

#### Layer 3：感情线配置
- 感情线类型：官配 / 多线 / 无CP / 暧昧留白
- 感情节奏表：初次相遇 → 共同经历 → 感情转折 → 确定关系（标记章节区间）
- 感情障碍设计：阶层差距 / 立场对立 / 误会 / 宿命冲突
- 反套路感情：拒绝"一见钟情无理由"，每段感情必须有充分动机

#### Layer 4：反派分层设计
| 层次 | 定位 | 设计要点 | 出场时机 |
|------|------|---------|---------|
| 初级反派 | 前期垫脚石 | 性格单一，强化主角成长 | 1-20章 |
| 中级反派 | 中期劲敌 | 有背景、有动机、有智慧 | 20-80章 |
| 高级反派 | 后期大BOSS | 与主角有深层联系 | 80章+ |
| 影子反派 | 暗线操控者 | 真相揭露引发世界观颠覆 | 贯穿/后期 |

- **镜像对抗原则**：每个反派都是主角某一面的镜像映射

#### Layer 5：配角群像
- 盟友型：与主角互补，各自有独立故事线
- 导师型：有退出机制（死亡/隐退/背叛）
- 搞笑型：调节节奏，不能沦为工具人
- 反派型配角：亦敌亦友，立场随剧情变化
- 每个配角必须回答：**没有这个角色，剧情会失去什么？**

#### Layer 6：角色档案标准化
```
名称：
定位：（主角/反派/配角/龙套）
外貌描述：（关键特征，50字内）
性格关键词：（3-5个）
核心动机：（一句话）
能力/特长：
缺陷/弱点：
关键关系：
角色弧线：（初→中→末的变化）
首出场章节：
```

### 二、世界观设计（5层体系）

#### Layer 1：世界规模与基调
- 世界规模：小型 / 中型 / 大型 / 超大型
- 时代基调：古代/近代/现代/近未来/远未来/架空
- 世界氛围：黑暗/光明/写实/浪漫/赛博/废土/学院

#### Layer 2：物理与超自然规则
- **力量体系等级**：明确等级划分 + 每级突破条件 + 越级代价
- **元素属性**：五行/光暗/时空等的克制关系
- **力量天花板**：世界最高战力限制

#### Layer 3：社会与势力格局
- 主要势力列表（宗门/家族/国家/组织/教会）
- 势力关系网：同盟/敌对/中立/利益交换
- 社会阶层结构：金字塔式/流动式/分裂式
- 经济体系：货币/资源/贸易/贫富差距

#### Layer 4：文化与历史
- 世界编年史：至少 5 个纪元节点
- 文化特征：语言/宗教/节日/禁忌/风尚
- 科技水平：与现实的差距

#### Layer 5：时间线锚点
- 故事起点在编年史的位置
- 即将发生的世界级事件（倒计时）
- 主角对历史进程的影响潜力

### 三、金手指设计

| 类型 | 说明 | 适用题材 | 风险 |
|------|------|---------|------|
| 系统流 | 游戏化界面、任务、奖励 | 都市/游戏/异界 | 容易套路化 |
| 重生流 | 携带记忆回到过去 | 都市/商战/修仙 | 蝴蝶效应复杂 |
| 穿越流 | 携带现世知识/技能 | 历史/异界/末世 | 知识优势期有限 |
| 传承流 | 获得前辈记忆/能力 | 修仙/武侠 | 继承节奏要快 |
| 血统流 | 特殊血脉觉醒 | 奇幻/都市 | 注意平衡性 |
| 器物流 | 持有特殊物品 | 全题材 | 防止过度依赖 |

**金手指规范表：**
```
名称：
类型：
获得时机：（第 X 章）
核心功能：
使用限制：
成长路径：
可见度：   （暴露给谁/何时暴露）
使用代价：  （每次使用消耗什么）
弱化机制：  （中后期如何限制以避免无敌）
```

### 四、创意约束包
- 从灵感 + 反套路库生成 2-3 套创意包（卖点 + 反套路 + 硬约束）
- 硬约束示例："主角必须在 300 章内从凡人到飞升"
- 五维评分 → 用户确认最终方案

### 五、生成设定契约（Setting Contract）

将以上所有设定转化为 **机器可读的设定契约**（JSON 格式），这是根治"逻辑矛盾、战力体系崩溃"的根本机制。设定契约不是设定的替代品，而是设定的"可执行版本"——Reviewer Agent 在写章后自动对照契约做一致性检查，无需人工检查清单。

**输出位置**：`.story-system/MASTER_SETTING.json`

**契约必须包含**：
- 力量体系等级列表（每级的能力/限制/边界时间范围）
- 世界规则硬约束（不可违反的天条/物理规则）
- 角色核心性格与行为禁区
- 角色力量时间线（每章区间对应的预期等级）
- 未揭示反派的行为限制（防止提前暴露）
- 活跃伏笔列表（埋设章节/计划回收章节/提前暴露禁区）
- 设定变更日志

**详细规范详见**：`setting-contract-schema.md`

```
  ├── 感情线设计.md
  ├── 世界观.md
  ├── 力量体系.md

  ├── MASTER_SETTING.json   — ★ 设定契约（核心产出，自动验证用）
  └── power_contract.json   — 力量体系契约（可选，精细化控制时用）
```

## 质量闸门
- [ ] 主角是否有至少 1 个影响决策的缺陷？
- [ ] 是否有至少 3 层反派的完整设计？
- [ ] 世界观是否有明确的规则边界？
- [ ] 金手指是否有使用限制与代价？
- [ ] 每个配角是否都有独立动机？
- [ ] ★ 设定契约（MASTER_SETTING.json）已生成？— **缺少此文件后续所有写章流程将无法进行自动设定验证**

## 故障恢复
| 问题 | 处理方式 |
|------|---------|
| 角色设计缺乏灵感 | 从 character-design.md 中调用角色模板 |
| 金手指过于强大 | 检查弱化机制字段，强制添加至少 2 条限制 |
| 世界观逻辑矛盾 | 使用 setting-consistency.md 做逐项检查 |
