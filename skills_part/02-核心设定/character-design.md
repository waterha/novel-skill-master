# 角色设计指南（Character Design Guide）

角色是小说的灵魂。本文档提供从零到完整角色设计的系统方法。

---

## 一、角色构建核心公式

```
可信角色 = 清晰欲望 + 致命缺陷 + 复杂动机 + 成长弧线
```

### 欲望（Desire）
角色想要什么，驱动他行动的根本动力。
- **表层欲望**：前10-20章可达成的小目标（赚钱、通过考试、找到某物）
- **深层欲望**：贯穿全文的核心驱动力（证明自己、被爱、复仇、守护）
- 欲望越具体，角色越鲜活

### 缺陷（Flaw）
阻碍角色达成目标的性格弱点。
- 必须影响关键决策，不能只是装饰
- 缺陷在关键时刻会导致失败
- 好的缺陷是优点的另一面（如勇敢→鲁莽、细心→多疑）

### 动机（Motivation）
为什么想要？动机必须让读者共情。
- 过去创伤驱动（最有效）
- 当下危机驱动
- 未来愿景驱动

### 成长弧线（Arc）
角色从起点到终点的变化路径：
```
起点：被缺陷支配 → 过程：逐步意识到缺陷 → 高潮：缺陷导致重大损失 → 终点：克服/接纳缺陷
```

## 二、角色原型库

### 12种经典原型

| 原型 | 核心欲望 | 核心缺陷 | 故事功能 |
|------|---------|---------|---------|
| 英雄 | 证明自己 | 傲慢/自大 | 战胜外在威胁 |
| 孤儿 | 寻找归属 | 信任问题 | 建立关系 |
| 流浪者 | 寻找真相 | 不安现状 | 推动探索 |
| 战士 | 守护他人 | 无法示弱 | 对抗邪恶 |
| 守护者 | 保护弱者 | 过度牺牲 | 提供保护 |
| 爱人 | 连接他人 | 依赖 | 情感驱动 |
| 统治者 | 控制 | 傲慢/专制 | 权力主题 |
| 智者 | 理解世界 | 过度理性 | 提供指引 |
| 愚者 | 享受当下 | 不负责任 | 喜剧/缓解 |
| 叛逆者 | 打破规则 | 自我毁灭 | 颠覆现状 |
| 魔法师 | 改变世界 | 傲慢 | 个人成长 |
| 创造者 | 创造不朽 | 完美主义 | 艺术主题 |

## 三、角色关系网络

### 关系三角
稳定的角色关系至少需要三个节点：
```
主角 ── 盟友（支持）
  │
反派 ── 中立角色（立场可变）
```

### 关系动态设计
- 关系不是静态的，会随时间变化
- 每个关系有独立的弧线（从A→B→C）
- 关键关系变化标记在章节大纲中

## 四、对话风格区分

每个角色应有独特的说话方式：

| 维度 | 变化范围 |
|------|---------|
| 句长 | 长句(深思型) ↔ 短句(行动型) |
| 词汇量 | 丰富(高知) ↔ 贫乏(朴素) |
| 语速 | 快(急躁) ↔ 慢(沉稳) |
| 礼貌度 | 正式 ↔ 随意 ↔ 粗鲁 |
| 口头禅 | 有 ↔ 无 |
| 情绪表达 | 直接 ↔ 克制 |

## 五、角色一致性检查

- [ ] 角色行为是否符合其核心价值观？
- [ ] 角色的决定是否受其缺陷影响？
- [ ] 角色的说话方式是否有辨识度？
- [ ] 角色的成长弧线是否贯穿全文？
- [ ] 角色的过去是否影响现在决策？
- [ ] 每个配角的存在是否对主角产生作用？
