# 世界规则指南（World Rules Guide）

构建可信虚构世界的规则体系。

---

## 一、世界构建的三个层次

```
Layer 1：物理层 — 世界怎么运转（天圆地方/星球/位面）
Layer 2：社会层 — 人怎么组织（制度/文化/阶层）
Layer 3：意义层 — 世界为什么是这样（历史/神话/目的）
```

---

## 二、核心规则设定

### 物理规则
- 世界的基本结构（大陆/星球/位面/浮空岛）
- 时间流速（与现实一致/有差异）
- 重力/气候/季节规律

### 超自然规则（如适用）
- 力量来源：魔力/灵力/精神力/信仰力
- 使用限制：消耗/冷却/代价/反噬
- 获取方式：天赋/学习/契约/传承

---

## 三、社会规则

### 阶层结构
- 社会分层的依据（力量/血统/财富/知识）
- 阶层流动的可能性
- 不同阶层的权利和义务

### 经济体系
- 货币形式（金币/灵石/贡献点）
- 核心资源（什么是最值钱的）
- 贫富差距程度

### 文化规则
- 主要禁忌（什么不能说/不能做）
- 重要节日/仪式
- 主流价值观（力量至上/和平共处/适者生存）

---

## 四、世界规则清单

- [ ] 世界的基本物理规则在第30章和第1章保持一致
- [ ] 特殊能力有明确的使用限制
- [ ] 社会的运转逻辑自洽
- [ ] 世界的规模和探索范围有边界
- [ ] 存在角色"做不到"的事情（规则不是万能的）
- [ ] 规则之间有互动（社会受物理影响，文化受社会影响）
- [ ] 有明确的"规则例外"清单（如果有的话）
