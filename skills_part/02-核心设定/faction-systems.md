# 势力系统设计（Faction Systems Design）

小说中势力/组织的关系网络设计指南。

---

## 一、势力设计三要素

```
势力 = 目标 + 资源 + 规则
```

1. **目标**：这个势力想要什么？（统治/财富/知识/生存）
2. **资源**：它用什么实现目标？（武力/金钱/信息/人脉）
3. **规则**：内部怎么运转？（等级/贡献/血缘/力量）

---

## 二、势力类型

### 1. 政治型
- **特征**：以领土/人口统治为核心
- **示例**：帝国、王国、城邦
- **内部冲突**：王位继承、派系斗争、改革vs保守
- **故事潜力**：权谋、战争、外交

### 2. 经济型
- **特征**：以财富/资源积累为核心
- **示例**：商会、钱庄、矿业集团
- **内部冲突**：利益分配、市场竞争、继承权
- **故事潜力**：商战、收购、垄断

### 3. 武力型
- **特征**：以武力/战斗力量为核心
- **示例**：宗门、门派、佣兵团、骑士团
- **内部冲突**：首席之争、功法传承、正邪之争
- **故事潜力**：比武、叛变、远征

### 4. 知识型
- **特征**：以知识/信息为核心
- **示例**：学院、图书馆、情报组织、占星会
- **内部冲突**：知识垄断、学术路线之争
- **故事潜力**：秘密揭示、考古、预言

### 5. 隐秘型
- **特征**：隐藏在暗处，操控明面世界
- **示例**：刺客组织、秘密结社、 cult
- **内部冲突**：忠诚测试、叛徒清理
- **故事潜力**：潜入、背叛、真相揭露

## 三、势力关系网

### 关系类型
| 关系 | 特征 | 故事用途 |
|------|------|---------|
| 同盟 | 共同利益，互相支持 | 联合对抗更强敌人 |
| 敌对 | 根本利益冲突 | 直接冲突 |
| 竞争 | 目标相同，手段不同 | 间接对抗 |
| 利用 | 一方利用另一方 | 背叛伏笔 |
| 依附 | 一方从属于另一方 | 压迫/反抗主题 |
| 中立 | 互不干涉 | 可争取的力量 |

### 关系可视化工具
```
        [帝国]
       ╱  ↓   ╲
   [宗门] ← → [商会]
      ↓         ↓
   [教会]    [佣兵团]
```
箭头表示影响/敌对/同盟方向。

---

## 四、势力弧线

势力本身也应随故事发展而变化：

| 阶段 | 势力状态 | 故事作用 |
|------|---------|---------|
| 开端 | 稳定/平衡 | 背景设定 |
| 发展 | 内部矛盾浮现 | 支线冲突 |
| 转折 | 重大变故（分裂/合并/覆灭） | 剧情推动 |
| 结局 | 新秩序建立 | 主题收束 |
