# 力量体系设计（Power Systems Design）

奇幻/玄幻/仙侠等题材的力量体系构建指南。

---

## 一、等级体系设计

### 经典九阶模型
```
练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫
```

### 设计原则
1. **每个等级有明确标志**：突破后能做什么、不能做什么
2. **升级有代价**：时间/资源/身体/情感
3. **天花板明确**：世界最高战力是什么
4. **越级有限制**：越级战斗必须以某种代价换取

---

## 二、力量来源

| 来源 | 特征 | 示例 |
|------|------|------|
| 血脉 | 与生俱来，不可剥夺 | 龙族血脉、神裔 |
| 修炼 | 后天积累，勤奋可成 | 内力、灵力、查克拉 |
| 契约 | 与外力达成协议 | 恶魔契约、精灵契约 |
| 传承 | 继承自前人 | 功法传承、记忆传承 |
| 装备 | 依赖外物 | 法器、神器、武器 |
| 觉醒 | 特定条件下触发 | 血脉觉醒、天赋觉醒 |

---

## 三、能力克制关系

### 五行/元素克制
```
金 → 木 → 土 → 水 → 火 → 金
```
克制关系让战斗更有策略性，避免单纯的力量碾压。

### 克制设计原则
- 克制不是绝对压制（7:3开比较合理）
- 高阶可以压制低阶（等级差大于克制关系）
- 克制可以被技巧/装备/战术抵消

---

## 四、力量体系检查

- [ ] 等级划分清晰，各阶段能力边界明确
- [ ] 升级有门槛/代价，不是自动获得
- [ ] 力量天花板明确，后期不会力量膨胀失控
- [ ] 存在克制/制约关系
- [ ] 存在无法用力量解决的问题（给非武力角斗空间）
- [ ] 力量的代价/限制在故事中被遵守
- [ ] 特殊能力有使用限制（冷却/消耗/副作用）
