# 场景描写（Scene Description Guide）

场景描写的技巧和方法。

---

## 一、场景描写的作用

- **建立氛围**：让读者感受到场景的情绪
- **提供信息**：让读者了解角色在什么样的环境中
- **推动情节**：环境中的元素触发角色的行动
- **映射心理**：环境反映/反衬角色的内心状态

---

## 二、场景描写的层次

### 从外到内
```
远景：整体环境（战场/城市/森林）
中景：角色周围的空间（房间/街道/角落）
近景：角色接触的细节（道具/人物表情）
```

### 感官维度
| 感官 | 适用场景 | 效果 |
|------|---------|------|
| 视觉 | 所有场景 | 建立基本画面 |
| 听觉 | 悬疑/战斗/日常 | 增强临场感 |
| 触觉 | 动作/亲密/恐惧 | 增强代入感 |
| 嗅觉 | 封闭空间/食物/自然 | 唤起记忆 |
| 味觉 | 食物/受伤/情感 | 增加细节 |

---

## 三、有效 vs 无效描写

### 无效描写（信息倾倒）
> "这座城市有500万人口，占地面积2000平方公里，建于..."
（读者不需要百科词条）

### 有效描写（通过角色感知）
> "走出车站，一股潮湿的热气扑面而来。街上的人很多，每个人都在看手机。他第一次来这座城市，不知道这个方向对不对。"
（读者通过角色的体验了解城市）

---

## 四、场景描写原则

- **少即是多**：2-3个细节足以建立画面
- **服务剧情**：描写的每个细节应该对剧情/氛围/人物有贡献
- **通过角色之眼**：场景是通过角色的视角看到的
- **节奏控制**：高潮时描写精简，舒缓时描写丰富
