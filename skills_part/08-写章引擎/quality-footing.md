# 写作质量定锚（Quality Footing Guide）

## 概述

长篇写作的质量不是恒定的——写得越快，质量越容易下滑，而且这种下滑往往自己察觉不到。本文档提供几项前置性的"定锚"手段，在写作开始前就把质量基准稳住，而不是写完了再来修补。

---

## 零、每5章自动定锚机制

写作质量下滑是一个渐进的过程，单章检查难以捕捉这种趋势。本技能内置了一个**每5章强制触发**的写作状态调整机制：

**触发时机**：每次 `novel-write --full` 启动时，Step 0 预检会自动调用 `tools/quality_footing.py check`。
- 如果距上次质量重置已满5章 → 输出质量调整指令，重置计数器
- 如果未满5章 → 沉默通过

**触发后的效果**：
```
写作状态调整（第X章）
├── 1. 破折号趋势检查 → 上升则下章预算强制降到3次
├── 2. 句式回顾 → 扫最近3章，检查主语/链式句/解释句
├── 3. 模糊词检查 → 超标则下章刻意压减
├── 4. 节奏调整 → 高强度章节后安排慢节奏过渡
├── 5. 设定一致性 → 快读MASTER_SETTING.json当前约束
└── 6. 伏笔检查 → 检查接近回收时机的伏笔
```

**原理**：5章大约是一周到两周的日更量，这个频率刚好足够让"写顺手了开始松懈"的苗头在固定节点被截住，又不至于频繁打断写作节奏。

## 一、质量定锚的平衡原则

质量定锚必须同时包含两类规则：**削减型**（去除坏的东西）和**填充型**（确保好的东西足够多）。只有削减没有填充，章节会越写越短、越来越干。

```
质量 = 削减坏习惯 + 填充好内容
```

削减型规则：破折号、模糊词、解释句、链式句、连续主语——告诉你"不要做什么"。
填充型规则：章节体量、场景深度、对话密度——告诉你"要做什么"。

**两类规则必须同时执行，缺一则失衡。**

---

## 二、填充型定锚

### A. 章节体量：每章净内容量 ≥ 4,500字节

网文单章的标准体量是2,000-3,000字（约4,500-7,000字节）。低于4,500字节的章节通常存在内容填充不足的问题。

**检查方式**：写完后检查文件字节数。低于4,500字节的，需要回看是否有场景被压缩了、对话被省略了、过渡被跳过了。

**体量不足的常见原因**：
| 原因 | 表现 | 修复方式 |
|------|------|---------|
| 场景展开不够 | 一个情节点用3段写完就切走了 | 每个场景至少有一处"留白"——让角色在里面多待一会儿 |
| 对话密度低 | 独白多、对话少 | 能用对话推进的信息不要用叙述来写 |
| 过渡被跳过 | "几天后""一个月后"一句话带过 | 重要过渡至少写一段环境或状态变化 |
| 章节结束过早 | 情节走到一个点就切章了 | 章节结束应该落在"一段完整的剧情单元"之后，而不是停在半路 |

### B. 对话密度：每章至少有一段完整的对话交换（一来一回≥4句）

对话天然撑篇幅，同时提升可读性。如果一章全是独白或叙述说明，说明叙事方式出了问题。

**标准**：
- 有对手戏的章节：至少一段完整的对话交换（4句以上一来一回）
- 无对手戏的章节（独行、回忆、修炼）：至少有一处内心独白或对某个事物的"追问"（连续追问2次以上，推进思考深度）

**注意**：对话不是用来灌水的——每一句对话都要承担至少一个功能（推进情节/塑造性格/传递信息/制造冲突）。

### C. 场景容量：每章至少有2-3个完整的场景

一个"完整的场景"包含：环境建立 + 人物行动 + 结果/转折。如果一个章节只有一个场景就结束了，说明要么场景写得太长没有切分，要么内容量不够。

**典型分布**：
| 章节类型 | 场景数 | 示例 |
|---------|:------:|------|
| 战斗/行动章 | 2-3个场景 | 战前准备 → 交战 → 战后收束 |
| 对话/文戏章 | 2-4个场景 | 见面 → 交锋 → 转折 → 散场 |
| 过渡章 | 2-3个场景 | 出发 → 途中见闻 → 到达新地点 |

如果一个章节少于2个场景且字节数低于4,500，说明这一章在"赶路"而不是"展开"。

## 三、削减型定锚

### 1. 破折号：每章不超过8个

实施方式：
- 写完后全文搜索 `——`，数一遍。
- 超过8个的，把能用句号、逗号、冒号替代的替换掉。
- 特别注意"意识到——""发现——""看到——"这三类，它们几乎永远是多余的。

### 2. 每章至少一段"不推进剧情"的静物描写

网文最常见的质量问题是"太赶了"——每一行都在推情节，没有给读者喘息的间隙。解决办法很简单：每章至少安排一段纯粹的环境/氛围/静物描写，字数不限，唯一的要求是**这段描写不推进任何剧情**。

好例子（第25章）：
> 沈青衣蹲在溪边洗手。溪水从她指间流过，带着细碎的反光。
> 远处传来阵法峰上弟子练功的喝声，隔着一段距离，听起来模模糊糊的。

坏例子：
> 溪水很清。沈青衣洗完了手，站起来说："你的伤怎么样了。"
> （环境描写停留在"景色很美"的层面，两句后就回到对话推剧情）

原则：让读者在场景里"待一会儿"再走。

### 3. 减少"像是""仿佛""某种""一种"等模糊修饰词

这类词在写作中有合法的位置，但问题是它们会不知不觉地膨胀——原本要写"他的手在抖"，写成"他的手像是在微微颤抖"，语气就弱了。不是要完全禁用，而是写完一章后搜一下这几个词，删掉那些确实不需要的。

替换办法：
| 原文 | 替换 |
|------|------|
| 像是被什么东西击中了 | 被击中了 |
| 他的脸上浮现出一种……的表情 | 他的脸上浮现出……的表情 |
| 仿佛整个世界都在旋转 | 世界在旋转 |
| 有一种说不出的感觉 | 直接写具体感受，或不写 |

### 4. 场景结束后不要加解释句

这是最容易形成习惯的AI痕迹：一个场景写完后，加一句"这意味着他的人生从此改变了"或者"这让他明白了XX道理"。好的写法是让场景本身说话，场景结束就停。

原文：
> 剑尖停在慕容武的喉咙前。他输了。
> 陈天收起剑，走下比武台。这一战让他明白了一个道理：修为差距是可以靠战术弥补的。
> （最后一句是多余的）

改为：
> 剑尖停在慕容武的喉咙前。他输了。
> 陈天收起剑，走下比武台。

道理让读者自己总结。如果场景写到位了，他们能看懂。

### 5. 不要连续三句用同样的主语

典型模式：
> 他拔出剑。他冲了过去。他刺向对方的胸口。
> （连续三句"他"开头，节奏死板）

改法：
> 他拔出剑，冲了过去。剑尖直刺对方胸口。
> （合并主语，或者把其中一句换成"剑尖"做主语）

### 6. 链式句拆解

链式句是"他做了A——B发生了——然后C——这导致了D"用破折号或逗号串成一整句。超过三个连接点就必须拆。

原文：
> 陈天站在沙盘前，将阵旗插在灵脉交汇处，看到灵脉改道后，他明白了天阵子说的"修改规则"是什么意思。

拆解：
> 陈天站在沙盘前，将阵旗插在灵脉交汇处。
> 灵脉改了道。
> 他明白天阵子说的"修改规则"是什么意思了。

## 二、写前自检（每次开始写新章前快速过一遍）

1. 上一章写完时的状态：赶？正常？状态不好？
   - 如果上一章是赶出来的，这一章先写一段静物描写再推剧情。
2. 上一章的破折号超限了吗？
   - 超了 → 这一章优先用句号和逗号。
3. 连续写了几章了？
   - 3章以上无间断 → 至少放慢到每章花正常时间的1.5倍。
4. 手边有分章大纲吗？
   - 有 → 按大纲的结构写，不跳步。
   - 没有 → 停下来，先确认大纲再写。

## 三、质量降级信号

以下信号出现任意一个，说明质量已经开始下滑，需要主动干预：

| 信号 | 表现 | 干预手段 |
|------|------|---------|
| ★ 章节字节数低于4,500 | 内容量不足 | 回看场景/对话/过渡是否有被压缩 |
| ★ 连续3章字节数递减 | 越写越短的趋势 | 下一章强制写到5,000字节以上 |
| ★ 连续3章没有完整对话交换 | 对话密度过低 | 下一章增加至少一段完整对话（一来一回≥4句） |
| ★ 单章只有1个场景 | 场景展开不充分 | 下一章至少拆成2-3个场景 |
| 破折号超过8个/章 | 标点使用失控 | 写完后全文替换一轮 |
| 连续3句"他/她"开头 | 句子结构单一 | 合并主语或换主语 |
| "像是"出现超过3次/章 | 模糊修饰膨胀 | 搜"像是"，删掉不必要的 |
| 出现"他意识到/他发现/他感到+破折号" | 万能破折号模式 | 全部换成逗号或句号 |
| 场景结束后跟了解释句 | 过度解释 | 直接删掉解释句 |
| 没有静物描写的纯推进章节 | 节奏过紧 | 至少加一段环境描写 |
| 连续3章以上没有检查质量 | 注意力分散 | 每写一章立即做一次全面检查 |
