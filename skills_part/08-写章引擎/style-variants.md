# 风格变体（Style Variants）

在保持整体风格一致的前提下，为不同场景提供风格变体。

---

## 一、场景风格变体

### 战斗场景
- 短句为主，3-7字
- 动作描写为主，减少心理描写
- 快节奏，段落短
- 感官聚焦：视觉+触觉+听觉

### 情感场景
- 长句可适度增加
- 内心描写为主
- 节奏放慢，留白增加
- 感官聚焦：触觉+嗅觉

### 悬疑场景
- 细节描写密集
- 节奏适中，适当拖慢
- 克制情感表达
- 感官聚焦：听觉+视觉

### 对话场景
- 对话体为主
- 动作/表情作为语气标签
- 节奏根据剧情需要调整
- 潜台词重于字面意思

---

## 二、章节位置风格变体

| 章节位置 | 风格倾向 |
|---------|---------|
| 开篇3章 | 最精雕细琢、信息量适中 |
| 中段章节 | 节奏稳定、效率优先 |
| 高潮章节 | 短句密集、情绪饱满 |
| 过渡章节 | 轻松自然、可适度放慢 |
| 结局章节 | 呼应开篇风格、情感收束 |
