# 破折号使用限制（Dash Restriction Guide）

控制破折号过度使用，消除 AI 写作中后期最顽固的痕迹之一。

---

## 一、为什么需要限制破折号

破折号在中文写作中有其合法用途，但 **AI 模型在中后期写作中呈现显著的破折号滥用倾向**，表现为：

| 阶段 | 破折号密度特征 | 问题 |
|------|---------------|------|
| 前期（1-20章） | 正常，~3-5次/章 | 尚可接受 |
| 中期（21-100章） | 快速攀升，8-15次/章 | 破折号成为AI默认的"万能转折手段" |
| 后期（100章+） | 严重依赖，15-25次/章 | 形成 pattern，读者明显察觉 |

**破折号过多带来的问题：**
1. **节奏单一**——每次破折号都是一个"停顿—转折—推进"的节奏，用多了导致全文节奏千篇一律
2. **削弱真正需要的破折号**——当每个重要时刻都用破折号，那真正的关键转折反而没了冲击力（狼来了效应）
3. **AI 痕迹**——读者可能说不出"破折号太多"，但会直觉感到"这段读起来像AI写的"
4. **打断阅读流**——破折号强制读者停顿，过多停顿让阅读体验支离破碎

---

## 二、破折号的合法用途（可保留）

以下四种情况可使用破折号，**但每章总数不得超过 5 次**：

### 1. 语意转折（最常用，但最容易被滥用）

```
✅ "他说他爱我——但他转身就娶了别人。"
✅ "她本该是最了解我的人——也是最恨我的人。"
```

**限制**：语意转折类破折号每章不超过 2 次。

### 2. 突然中断或话题切换

```
✅ "我觉得这件事应该——不对，你刚才说什么？"
✅ "他推开门，眼前的一幕让他把要骂的话全咽了回去——"
```

**限制**：中断类破折号每章不超过 1 次。

### 3. 解释说明（跟在名词后补充说明）

```
✅ "三个人——李铭、方旭和我——被叫到了办公室。"
✅ "他只需要一样东西——证据。"
```

**限制**：解释说明类破折号每章不超过 2 次。

### 4. 声音延长或特殊语气

```
✅ "你——你居然——"他气得说不出话。
✅ "来——了——"远处传来拖长了的喊声。
```

**限制**：语气延长类破折号每章不超过 1 次。

## 三、需要替换的破折号滥用模式

以下模式在出现时应当立即替换。**这些占所有破折号滥用的大约 70%。**

### 模式1：万能"意识到/发现"类（最多发）

```
❌ "他突然意识到——那个人就是凶手。"
❌ "他这才发现——这根本不是巧合。"
✅ "他突然意识到，那个人就是凶手。"
✅ "他这才发现，这根本不是巧合。"
```

**替换方案**：冒号、逗号或直接说，效果完全相同。破折号不增加任何信息量。

### 模式2：万能"转折推进"类（中后期大量出现）

```
❌ "林轩冷冷地看着他，手中的剑已经出鞘——"
❌ "那间屋子的门紧闭着，窗户却是开的——"
```

**替换方案**：直接叙述，用句号断开。读者不需要破折号来提示"下文要转折了"。

| 原文 | 替换 |
|------|------|
| `A——B` | `A。B` / `A，B` / `A：B` |
| `A——但B` | `A。但B` / `A，可B` / `然而B` |
| `A——B。C——D` | 拆成两到三个独立的句子 |

### 模式3：万能"铺垫结局"类（章尾钩子滥用）

```
❌ "可当她看清那个人的脸时，她的笑容僵住了——"
❌ "他不知道自己即将面对的是什么——"
```

**替换方案**：用省略号、直接动作描写、或角色反应来代替破折号的"悬念感"。

| 原文 | 替换方案 |
|------|---------|
| `笑容僵住了——` | `笑容僵在脸上。`（句号收尾，干脆） |
| `不知道……是什么——` | `不知道是什么。`（直接陈述） |
| `就在这时候——` | `就在这时候，`（逗号，一样有效） |

### 模式4：万能"内心波动"类

```
❌ "他想反驳，但话到嘴边又咽了回去——没有必要。"
❌ "她在心里叹了口气——已经不重要了。"
```

**替换方案**：直接写内心活动，不需要破折号来提示"以下为内心想法"。

```
✅ "他想反驳，但话到嘴边又咽了回去。没有必要。"
✅ "她在心里叹了口气。已经不重要了。"
```

### 模式5：万能"列举说明"类

```
❌ "他包里装满了各种装备——匕首、绳索、干粮、药品。"
❌ "她还需要的只有一样东西——一个机会。"
```

**替换方案**：列举用逗号/冒号，单点说明直接用"是"或冒号。

```
✅ "他包里装满了各种装备：匕首、绳索、干粮、药品。"
✅ "她还需要的只有一样东西：一个机会。"
```

## 四、破折号的替代方案速查

| 原用途 | 推荐替代 | 示例 |
|--------|---------|------|
| 语意转折 | 逗号 + 转折词 | `但他——` → `但` / `可` / `不过` |
| 突然中断 | 省略号或动作描写 | `他刚要——` → `他刚要开口，又闭上了。` |
| 解释说明 | 冒号 `：` | `他只要一样东西——答案` → `他只要一样东西：答案` |
| 声音延长 | 省略号 `……` | `你——你——` → `你……你……` |
| 强调/铺垫 | 句号断开，独立成句 | `他看到了——那是一——` → `他看到了。那是一` |
| 章尾悬念 | 动作+反应，不靠标点 | `她正要开门——` → `她把手伸向门把手。` |
| 内心想法 | 直接写，句号收尾 | `他想——也许——` → `他想，也许。` |
| 多层级信息 | 拆成多个短句 | 见下方"拆解示例" |

### 拆解示例：一个破折号过多的段落如何修改

**修改前（AI默认输出，6个破折号）：**

> 陈默站在窗前——外面的雨下得很大——他想起三年前那个同样的雨夜——也是这样的天气，那个人离开了——不，是被逼走的——想到这里，他握紧了拳头——指甲陷进掌心。

**修改后（0个破折号）：**

> 陈默站在窗前。外面的雨下得很大。
>
> 他想起了三年前那个同样的雨夜。也是这样的天气，那个人离开了——不，是被逼走的。
>
> 想到这里，他握紧了拳头，指甲陷进掌心。

**对比**：修改后保留了 1 个必要的破折号（"被逼走的"的修正语意），其余全部用句号/段落代替。阅读节奏从"顿—顿—顿—顿—顿"变成了"舒缓—回忆—情绪爆发"的自然曲线。

## 五、章节审查清单

每章写完后，逐项检查：

- [ ] 全章破折号总数 ≤ 5 次（含对话）
- [ ] 无"意识到——""发现——""看到——""听到——"类万能破折号
- [ ] 段落末尾无"为了悬念而加的"悬空破折号
- [ ] 每个破折号都通过了"删掉是否影响理解"测试
- [ ] 连续3段内没有出现2次以上破折号（密集使用警告）
- [ ] 没有用破折号替代"逗号+转折词"的正常语法结构

**测试方法**：将全文所有 `——` 替换为空白，重读一遍。如果仍然能顺畅理解，说明这些破折号都是冗余的。

## 六、与 Anti-AI 检测联动的检查标准

将此标准加入 `novel-write.md` 的 Anti-AI 检测表中：

| 检测项 | 阈值 | 处理 |
|-------|------|------|
| 全章破折号总数 | ≤ 5 次/章 | 超限 → 每超1次计数为1个 minor issue |
| "意识到/发现/看到+破折号"模式 | 0 次 | 必须替换 |
| 段落末尾悬空破折号（悬念钩子类） | ≤ 1 次/章 | 超限替换为动作描写或句号收尾 |
| 连续3段内破折号密度 | ≤ 1 次/3段 | 超限 → 重构该区域，分散节奏 |
| "——但"结构 | ≤ 1 次/章 | "——但"几乎总可以用"但"直接开头 |

## 七、原因分析：AI 为什么在中后期大量使用破折号

了解原因有助于更主动地预防：

| 原因 | 说明 |
|------|------|
| **路径依赖** | AI在前几章"成功"使用了破折号（没被用户纠正），就会认定这是"好的写作风格"，在后文中复用的权重越来越高 |
| **万能缝合** | 破折号可以连接任何两个句子，不需要考虑"用什么转折词""分不分段""用句号还是冒号"——它是AI的万能胶 |
| **节奏偷懒** | 破折号创造一种"假装有节奏"的效果——两段文字之间加个破折号，看起来像是有意为之的停顿，实际上是放弃了真正的节奏设计 |
| **中后期退化** | 写作初期模型会仔细设计每句话的结构，中后期为了速度和容量开始走捷径，破折号就成了第一牺牲品 |

**预防策略**：
- 每 20 章做一次全篇破折号密度扫描（调用 `python tools/dash_tracker.py analyze --project-root <路径>`）
- 如果某章破折号超过 5 次，写下一章时有意识地降低到 3 次以下做平衡
- 主角性格激动/剧情紧张的场景中破折号允许适度增加（最多 8 次），但该场景结束后必须回落

### ★ 密度趋势追踪（由 Python 脚本自动化）

AI 的破折号滥用有一个关键特征：**密度会随章节推移指数级增长，而非保持恒定**。这意味着"每章检查阈值"是不够的——即使每章都控制在 5 次以下，总密度仍然可能在 50 章内翻倍。必须追踪趋势线，而不只是单点阈值。

**趋势追踪规则**：

```
写法1（仅检查单章阈值 → 密度递增）：
  第10章：4次  →  第30章：5次  →  第60章：5次  →  第100章：5次
  密度走势：100章内密度翻倍，但每章都"合格"

写法2（追踪趋势线 → 密度可控）：
  第10章：4次  →  第30章：3次  →  第60章：2次  →  第100章：2次
  密度走势：早期主动压低，为后期高潮场景留出配额空间
```

**执行方式（由 `tools/dash_tracker.py` 自动完成）**：
1. 写章提交后调用 `python tools/dash_tracker.py update --project-root <路径> --chapter <路径/第XX章.md>` 更新趋势数据
2. 脚本自动按每10章归档为一个 window，检测密度走势
3. 如果最近 10 章总数 > 前 10 章总数（密度上升趋势），**下一章的预算自动下调为 3 次**
4. 如果连续 3 个 10 章区间都呈现下降趋势，恢复默认预算 5 次
5. 趋势数据写入 `.story-system/dash_trend.json`，每次写章前由 Step 1 的 Context Agent 调用 `dash_tracker.py trend` 获取当前状态

**密度校准表**：

| 最近 10 章趋势 | 下一章预算 | 操作 |
|--------------|----------|------|
| 趋势下降（密度在收敛） | 5 次 | 正常起草 |
| 趋势持平 | 4 次 | 谨慎起草 |
| 趋势上升（密度在扩散） | 3 次 | 强制压低，每写 500 字暂停一次自检 |
| 密集区（单章 > 8 次） | 2 次 | 写完后必须全章替换一遍冗余破折号，确认每处都是必要的 |

> 💡 趋势校准由 `tools/dash_tracker.py trend` 自动计算并输出推荐预算。

## 八、各题材破折号容忍度参考

不同题材对破折号的容忍度不同。`tools/dash_tracker.py check --genre <题材>` 自动使用以下阈值：

| 题材 | 每章上限 | 说明 |
|------|---------|------|
| 都市/现实 | 3 次 | 口语化叙事，破折号过多显得做作 |
| 悬疑/推理 | 4 次 | 适当的破折号可制造悬念氛围，但不宜超过 |
| 言情/甜宠 | 4 次 | 内心戏中适度使用可接受 |
| 玄幻/仙侠 | 5 次 | 古风语境下容忍度稍高，场景变换频繁 |
| 科幻 | 3 次 | 逻辑性叙事，破折号应让位于精确描述 |
| 历史 | 5 次 | 半文半白，但过多破折号会破坏古风质感 |
| 搞笑/轻松 | 3 次 | 节奏轻快，破折号的停顿感会拖慢整体节奏 |

**注意**：以上为 **硬上限**，非推荐值。推荐值在上限的 60%。"
