# 润色指南（Polish Guide）

章节创作完成后的润色检查流程。

---

## 一、润色层次

```
L1: 基础纠错（错别字/标点/语法）
L2: 语感优化（句式/节奏/衔接）
L3: 深度优化（AI痕迹清除/风格统一）
```

---

## 二、L1—基础纠错

- [ ] 错别字修正
- [ ] 标点符号规范（中文全角标点）
- [ ] 破折号总数 ≤ 5 次/章（详见 dash-restriction.md）
- [ ] 段落不超过4行（网文规范）
- [ ] 对话引号使用正确

---

## 三、L2—语感优化

- [ ] 句子长度有变化，无连续3句长度相同
- [ ] 段落长度有变化，动作场景用短段
- [ ] 没有冗余修饰语（"非常""真的很""特别"）
- [ ] 长句拆解为短句（超过30字的长句需检查）
- [ ] 主语变化（避免连续多句以"他""她"开头）

---

## 四、L3—AI痕迹清除

- [ ] 无"此外""然而""值得注意的是"等AI高频词
- [ ] 无连续四字成语堆砌
- [ ] 无"首先…其次…最后"三段式
- [ ] 无"总而言之""由此可见"总结句式
- [ ] 无"感受到""意识到""心中涌起"等抽象情感标签
- [ ] 无"仿佛""宛如""似乎"等模糊词过度使用
- [ ] 一句话中"的"不超过2个

---

## 五、润色流程

```
起草 →  L1检查 → L2检查 → L3检查 → 终读
```
