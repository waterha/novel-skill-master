# Anti-AI 检测指南（Anti-AI Detection Guide）

识别和消除 AI 生成文本痕迹的具体操作指南。

---

## 一、AI高频词汇替换表

| 禁用词 | 替换方案 |
|--------|---------|
| 此外/另外 | 直接删掉或不用 |
| 然而/但是 | 换成"可""却""不过" |
| 值得注意的是 | 直接删除 |
| 需要强调的是 | 直接删除 |
| 彰显/诠释/赋能 | 换成具体动作描述 |
| 不禁/不由得 | 改为具体反应 |
| 油然而生 | 改为具体感受 |
| 心潮澎湃 | 改为具体动作 |
| 这一刻 | 直接删除或改为具体时间 |
| 仿佛/宛如/如同 | 删掉70%，保留30% |
| 似乎/好像 | 明确肯定的表述 |
| 璀璨/瑰丽/绚烂 | 改为具象描述 |

## 二、句式检测

### 问题句式1：三段式论证
```
❌ "首先，...其次，...最后..."
✅ 直接说结论，或自然过渡
```

### 问题句式2：总结式结尾
```
❌ "总而言之，这一天是..."
✅ 用行动/对话结尾，不要总结
```

### 问题句式3：抽象情感标签
```
❌ "他心中涌起一股复杂的情感"
✅ "他握紧拳头，指节发白"
```

### 问题句式4：破折号过度使用
```
❌ "他突然意识到——这不是巧合。"
❌ "他站在窗前——外面的雨很大——他想起三年前——"
✅ "他突然意识到，这不是巧合。"
✅ "他站在窗前。外面的雨很大。他想起三年前。"
```

**规则**：全章破折号 ≤ 5 次。详见 [dash-restriction.md](dash-restriction.md)。

---

## 三、四字成语检测

- 连续2个以上四字成语必须拆分
- 优先替换为口语化表达
- 保留那些确实有助于表达的成语（不超过每章5个）

---

## 四、检测流程

1. **运行自动检测脚本**：`python tools/anti_ai_check.py check --chapter <文件路径>`
   - 自动检测禁用词、三段式结构、总结式结尾、情感标签、「是……的」句式、四字成语密度、「的」字密度
   - 输出结构化 JSON，标注每个违规的位置和严重等级
2. 人工逐项检查高频词（参考脚本输出的 `banned_words` 列表）
3. 搜索"的"字密度（每句不超过2个）
4. 搜索"是……的"句式
5. 通读一遍，标记"读起来像AI"的段落
6. 逐段重写标记段落

### 通过标准
- 脚本输出 `anti_ai_force_check=pass`（评分 ≥ 60）
- 无禁用词
- 无三段式结构
- 四字成语 ≤ 5个/章
- 字数达标
- 通读自然流畅
