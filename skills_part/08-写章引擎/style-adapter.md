# 风格适配器（Style Adapter）

根据题材和剧情需要自动调整写作风格。

---

## 一、风格维度

| 维度 | 范围 |
|------|------|
| 叙事密度 | 极简 ↔ 细腻 |
| 句子长度 | 短句 ↔ 长句 |
| 词汇选择 | 通俗 ↔ 文雅 |
| 节奏 | 快速 ↔ 舒缓 |
| 情感表达 | 克制 ↔ 奔放 |

---

## 二、题材风格映射

| 题材 | 推荐风格 |
|------|---------|
| 玄幻/仙侠 | 有古风感、四字词适度、战斗场面短句为主 |
| 都市/现实 | 口语化、接地气、对话比例高（40%+） |
| 悬疑/推理 | 克制冷静、细节描写、节奏偏慢 |
| 言情/甜宠 | 细腻、情绪饱满、内心戏多 |
| 科幻 | 精准、逻辑清晰、术语使用合理 |
| 历史 | 半文半白、符合时代用语习惯 |

---

## 三、适配规则

- 全书的叙事风格基调在 Phase 1 确定
- 同一本书内风格基调保持一致
- 特殊章节（战斗/告白/悬疑）可在基调基础上做临时调整
- 风格调整不改变人物对话风格（角色说话方式不受影响）
