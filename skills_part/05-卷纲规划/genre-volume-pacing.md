# 各题材卷节奏模板（Genre Volume Pacing Templates）

不同题材有不同的节奏规律，本文档提供常用节奏模板。

---

## 玄幻/仙侠卷节奏

### 升级流
```
开篇(5%): 展示当前境界/困境
铺垫(20%): 获得升级契机（奇遇/指引/资源）
小高潮(30%): 成功突破/获得新能力
转折(45%): 遭遇同级对手/第一次越级挑战
中段反转(50%): 发现升级代价/暗藏风险
升压(65%): 强敌逼近/时间紧迫
最大危机(80%): 走火入魔/被围攻/护法受创
收束(95%): 危机解决or悬念 → 下卷预告
```

### 秘境/探索流
```
进入(10%): 发现秘境入口
探索(30%): 逐步深入，遭遇小怪/陷阱
竞争(20%): 与其他势力的争夺
揭秘(20%): 秘境核心/终极秘密
争夺(15%): 最终宝物/传承的争夺
出口(5%): 逃离/传送出来
```

## 都市卷节奏

### 商战流
```
布局(15%): 市场分析/资源整合
交锋(30%): 第一轮竞争（小胜/小败）
升级(20%): 整合更多资源/找到突破口
高潮(20%): 最终对决（收购/上市/谈判）
收尾(15%): 结果展示 + 新的威胁浮现
```

### 职场流
```
日常(15%): 职场现状/困境
事件(25%): 新项目/空降领导/危机
挣扎(25%): 带压工作/政治斗争
突破(20%): 关键成功/跳槽/创业
余波(15%): 新位置的新挑战
```

---

## 悬疑卷节奏

### 案件流
```
案发(10%): 发现案件/委托
调查(35%): 走访/取证/审讯嫌疑人
误区(20%): 错误方向 + 新线索
反转(15%): 关键证据/意料之外
真相(15%): 揭开谜底
余波(5%): 案件告破/遗留悬念
```

### 连环案流
```
第1案(20%): 发生 + 初查（引出连环特征）
第2案(20%): 发生 + 证实连环（模式浮现）
调查(25%): 并案调查，嫌疑人浮出水面
反转(20%): 方向错误/真凶另有其人
对决(15%): 最终交锋 + 真相
```

---

## 言情卷节奏

### 情感流
```
相遇(15%): 初次/再次相遇（有冲突/有趣）
靠近(25%): 被迫/主动接触，发现优点
升温(20%): 暧昧/心动/互相关心
障碍(25%): 误会/第三方/阶层/秘密
解决(15%): 障碍突破/关系确认/悬念
```

### 虐恋流
```
甜蜜(15%): 过往美好回忆/现在的假象
裂痕(20%): 矛盾初现/隐瞒
升级(25%): 误会深化/伤害
决裂(20%): 最大冲突/分离
和解(20%): 真相揭示/原谅/重聚
```

---

## 科幻卷节奏

### 探索流
```
发现(10%): 异常信号/现象
出发(15%): 组建队伍/出发
探索(30%): 逐步发现/遭遇危险
揭秘(20%): 核心秘密（技术/文明/真相）
冲突(20%): 如何应对这个秘密
结局(5%): 决定/代价/新问题
```
