# 核心约束检查表（Core Constraints Checklist）

审查时使用的核心约束检查项。

---

## 一、设定约束

- [ ] 角色能力不超过已建立的力量体系边界
- [ ] 世界观规则在全文保持一致
- [ ] 特殊能力的使用代价/限制被遵守
- [ ] 没有临时新增"刚好能解决当前问题"的能力

---

## 二、逻辑约束

- [ ] 因果链完整（A导致B，B导致C，没有跳跃）
- [ ] 角色决策基于已知信息
- [ ] 时间线前后一致
- [ ] 空间/距离合理（角色不会瞬间移动）

---

## 三、叙事约束

- [ ] 保持选定的叙事视角（不随意切换POV）
- [ ] 保持选定的时态（现在时/过去时不混乱）
- [ ] 人称一致（第一人称不突然变第三人称）
- [ ] 章节内的视角不跳跃

---

## 四、质量约束

- [ ] 每章字数在目标范围内
- [ ] 每章至少一个未解决的悬念
- [ ] 无AI生成痕迹（高频词、三段式、四字堆砌）
- [ ] 对话比例不低于20%（网文标准）

---

## 五、闸门检查

审查完成后，逐项确认：
- [ ] blocking issue 已全部处理
- [ ] 评分 ≥ 70（合格线）
- [ ] 所有检查项通过
