# 卖点设计指南（Selling Points）

如何设计、提炼和表达一部小说的核心卖点。

---

## 卖点的三个层次

```
表层卖点（吸引点击）：标题 + 简介 + 标签
    ↓
中层卖点（留住读者）：前三章的爽点 + 悬念
    ↓
深层卖点（读完本书）：人物魅力 + 主题深度 + 剧情张力
```

---

## 八种经典卖点模型

### 1. 金手指碾压
**核心**：主角拥有独特能力或优势，在他人无法解决的困境中轻松化解。

**示例**：
- "手握未来十年所有记忆，股市楼市尽在掌控"
- "绑定神豪系统，每天花不完一个亿"
- "鉴宝神瞳，古玩市场捡漏王"

**适用题材**：都市、玄幻、系统流
**风险**：容易失去悬念，需设计能力限制

### 2. 逆袭打脸
**核心**：主角从被看不起到惊艳所有人，反复制造爽感。

**示例**：
- "被逐出宗门三年，归来已是仙帝"
- "全公司都以为他是废物，直到他亮出身份"

**适用题材**：玄幻、都市、校园
**风险**：重复打脸会让读者疲劳，需每次升级

### 3. 悬念驱动
**核心**：核心谜题让读者一直想看下去。

**示例**：
- "每晚午夜，她都会收到一条来自未来的短信"
- "七天之内，必须找出隐藏在人群中的外星人"

**适用题材**：悬疑、科幻、惊悚
**风险**：谜底必须值得等待，否则前功尽弃

### 4. 情感虐恋
**核心**：主角间的感情纠葛牵动读者情绪。

**示例**：
- "结婚三年，他心里始终藏着白月光"
- "离婚后才发现，最爱你的人是我"

**适用题材**：言情、都市情感
**风险**：虐过头读者会弃书，需要甜虐平衡

### 5. 知识碾压
**核心**：主角在某领域的专业知识碾压对手。

**示例**：
- "穿越古代，我用现代医学震惊太医院"
- "重生1999，互联网巨头在我面前还只是学生"

**适用题材**：历史穿越、都市、商战
**风险**：专业知识必须扎实，否则露怯

### 6. 身份反转
**核心**：主角的真实身份被误解/隐藏，揭晓时造成震撼。

**示例**：
- "外卖小哥，竟是退役兵王"
- "公司前台，真实身份是千亿集团继承人"

**适用题材**：都市、言情、爽文
**风险**：身份揭晓必须在关键节点，不能太早

### 7. 黑暗丛林
**核心**：残酷的生存环境迫使主角不断变强。

**示例**：
- "全球丧尸爆发，只有杀够1000只才能获得 immunity"
- "这座岛上，每天都会淘汰一个人"

**适用题材**：末世、生存、游戏
**风险**：持续高压会让读者疲劳，需要喘息空间

### 8. 世界揭秘
**核心**：世界背后的真相逐层揭露，每一层都颠覆认知。

**示例**：
- "表面是普通的大学，实际上是一所超能力培训学校"
- "人类以为自己是地球主宰，其实只是外星人的实验品"

**适用题材**：科幻、奇幻、悬疑
**风险**：揭秘的节奏必须控制好，太快或太慢都不行

## 卖点表达公式

### 一句话卖点公式
```
当[事件发生]，[主角]必须[做某事]，否则[严重后果]。
但[独特优势]让他/她可以[独特方式]应对。
```

**示例**：
> 当丧尸病毒爆发、城市沦陷，普通快递员林北必须带着年幼的妹妹在末世活下去。好在他觉醒了一个看似没用的能力——他能在任何地方找到快递。

### 简介卖点结构
```
1. 开篇钩子（第一句抓住注意力）
2. 主角困境（让读者共情）
3. 金手指/转机（展示看点）
4. 悬念结尾（驱动点击下一章）
```

## 卖点验证清单

- [ ] 能在10个字内说清卖点吗？
- [ ] 目标读者看到卖点会想点开吗？
- [ ] 卖点在全书的保鲜期有多长？（能撑多少章）
- [ ] 这个卖点和市场上已有的作品有明显差异吗？
- [ ] 卖点能否支撑全书篇幅？
- [ ] 有没有配套的"展示场景"可以放到简介里？
