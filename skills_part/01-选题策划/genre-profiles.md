# 题材画像（Genre Profiles）

各题材的读者画像、平台偏好、创作难度评估。

---

## 玄幻/仙侠

| 维度 | 画像 |
|------|------|
| 核心读者 | 男频为主，16-30岁，学生/初入职场的男性 |
| 阅读场景 | 通勤、睡前、碎片时间 |
| 付费意愿 | 中等，对持续更新有要求 |
| 平台偏好 | 起点中文网、纵横中文网 |
| 竞争程度 | 🔴 极高（最大品类） |
| 创作难度 | ⭐⭐⭐⭐ 需要的世界观构建量大 |
| 成功要素 | 金手指有记忆点、升级节奏稳定、打脸爽感十足 |
