# 🎯 novel-topic — 选题策划与市场定位

## 概述
从零完成一本书的选题策划，包含市场调研、趋势分析、灵感碰撞、反套路设计，最终输出选题策划书。

## 所属阶段
第一阶段：选题策划

## 输入
- 用户偏好：题材偏好、目标平台、目标读者群
- 可选：灵感碎片、参考作品、市场数据

## 核心流程（6步深度调研）

### Step 1：平台与市场趋势扫描
- 确定目标平台（起点/纵横/番茄/晋江/飞卢等）
- 分析该平台当前热门品类 TOP20 的共同特征
- 识别蓝海品类（高需求低供给）
- 输出：平台画像卡片

### Step 2：灵感来源采集
用户从以下渠道选择（可多选）：
1. **原创想法** — 用户自带创意，直接进入评估
2. **参考书拆解** — 调用 deconstruction-agent 对指定作品进行结构化拆解（核心公式/爽点模型/节奏模板）
3. **市场趋势** — 基于平台热度数据推荐趋势题材
4. **反套路库** — 从 anti-trope 库中检索颠覆性创意
5. **创意组合** — 从 inspiration-collection 中做 A+B 混搭

### Step 3：题材定位与商业评估
- 确定主题材 + 辅题材（A+B 复合公式）
  - 如：都市 + 重生、仙侠 + 系统、科幻 + 竞技
- 目标字数评估（短篇 20-50 万 / 中篇 50-150 万 / 长篇 150-500 万+）
- 目标读者画像（年龄段/性别/阅读场景/付费意愿）
- 五维评分：**新鲜度 × 可读性 × 商业化 × 延展性 × 差异化**（各 1-10 分）

### Step 4：核心冲突设计
- 一句话故事（Logline）公式：`[主角] + [欲望] + [阻碍] + [stakes 赌注]`
  - 例："一个社畜程序员穿进自己开发的游戏，发现自己只是 NPC，必须突破系统限制才能回到现实"
- 三层冲突设计：
  - **表层冲突**：与对手/环境的直接对抗
  - **中层冲突**：与盟友/体系的价值观冲突
  - **深层冲突**：与自我的内心矛盾

### Step 5：反套路创新设计
- 检索 anti-trope 库中与选定题材相关的条目
- 设计 2-3 个反套路卖点
  - 例：传统"废材逆袭" → 反套路"天才堕落的救赎之旅"
- 评估反套路的**接受风险**（读者是否买账）
- 标注"保鲜期"（反套路能维持多少章不被读者看穿）

### Step 6：输出选题策划书

## 产出文件
```
选题/
  ├── 选题策划书.md        — 完整策划（题材/定位/冲突/卖点/风险）
  ├── 平台画像卡片.md       — 目标平台分析
  ├── 反套路设计.md         — 反套路方案与风险评估
  └── 竞品分析.md           — 同类作品对比表格
```

## 质量闸门
- [ ] 一句话故事是否清晰传递核心冲突？
- [ ] 五维评分是否 ≥ 30/50？
- [ ] 是否有至少 1 个可落地的反套路卖点？
- [ ] 目标读者画像是否具体可执行？

## 故障恢复
| 问题 | 处理方式 |
|------|---------|
| 用户无明确想法 | 引导从反套路库/创意组合中挑选 |
| 平台数据缺失 | 跳过定量分析，基于经验做定性判断 |
| 五维评分过低 | 返回 Step 3 重新选题材或做 A+B 调整 |
