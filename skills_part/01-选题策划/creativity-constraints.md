# 创意约束指南（Creativity Constraints）

设计小说时主动设置的约束条件，能激发更有创意的解决方案。

---

## 为什么需要约束？

> "创意生于限制，死于自由。" — 约束迫使作家在有限的框架内寻找最优解，反而催生出更有力的故事。

## 五种约束类型

### 1. 硬性字数约束
| 类型 | 约束 | 影响 |
|------|------|------|
| 短篇 | 20-50万字 | 情节紧凑，不能有废章 |
| 中篇 | 50-150万字 | 标准网文长度，节奏适中 |
| 长篇 | 150-500万+字 | 需要多卷规划，支线丰富 |

### 2. 时间线约束
- **故事时间跨度**：故事发生在多少天内/年内
- **倒计时装置**：如"主角必须在30天内突破筑基"
- **历史锚点**：不能改变的关键历史事件

### 3. 力量体系约束
- **天花板限制**：世界最高战力是什么
- **升级代价**：每次突破的代价是什么
- **越级惩罚**：越级挑战的后果

### 4. 角色行为约束
- **性格不可违背**：角色不能做出违反核心性格的事
- **信息不对称**：角色只能用已知信息做决策
- **动机一致性**：角色的行为必须符合其深层动机

### 5. 题材边界约束
- **保持核心题材特色**：如悬疑必须逻辑闭环
- **不越界**：都市文不突然出现修仙元素（除非是跨题材设计）
- **读者预期管理**：不被坏核心类型的读者约定

---

## 创意约束包示例

### 示例1：都市重生+商业
```
字数约束：100万字（中篇）
时间约束：重生到10年前，不能改变2008年金融危机
力量约束：无超自然力量，只能用知识和人脉
角色约束：主角不能变成冷血无情的商人，保持人性
题材边界：保持都市现实感，不加入系统/异能
```

### 示例2：仙侠+反套路
```
字数约束：200万字（长篇）
时间约束：主角必须在100章内从练气到金丹（快节奏）
力量约束：力量体系有明确的天花板（大乘期）
角色约束：主角不是废材，而是天才陨落重新崛起
题材边界：有修仙等级，但减少打怪升级，增加权谋
```

### 示例3：悬疑+都市
```
字数约束：60万字（中短篇）
时间约束：每起案件必须在24小时内解决（倒计时）
力量约束：无超自然能力，纯逻辑推理
角色约束：侦探有自己的心理创伤，会影响判断
题材边界：案件逻辑必须闭环，不能留坑
```

---

> **使用方式**：在完成选题和设定后，生成2-3套创意约束包供用户选择。约束越清晰，后续创作越不会跑偏。
