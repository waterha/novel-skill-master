# 📑 novel-arc — 剧情单元设计

## 概述
将每一卷拆分为 3-6 个剧情单元（Arc），每个单元有独立的起承转合，同时服务整卷的主线。

## 所属阶段
第六阶段：剧情单元设计

## 输入
- 卷纲（novel-plan 产出）
- 节拍表、时间线

## 参数
| 参数 | 说明 |
|------|------|
| `--volume N` | 指定要设计剧情单元的卷号（必填），如 `--volume 2` |

> **注意**：本 skill 为"**每卷一次**"的操作。`master continue` 会自动在所有卷上迭代执行。手动使用时必须指定 `--volume`。

## 核心流程

### Step 1：划分剧情单元
基于卷纲节拍表，将卷拆分为单元：

| 单元 | 功能 | 核心事件 |
|------|------|---------|
| Arc 1 | 引入/铺垫 | 主角进入新场景 |
| Arc 2 | 升级/探索 | 获得关键能力/信息 |
| Arc 3 | 转折/危机 | 第一次重大失败 |
| Arc 4 | 反击/高潮 | 逆袭/对决 |
| Arc 5 | 收束/过渡 | 解决遗留线索→引向下一卷 |

### Step 2：每单元设计模板
```
单元名称：
覆盖章节：
核心功能：（引入/铺垫/升级/转折/高潮/收束）
【起】开场情境：
【承】发展脉络（3-5个事件）：
【转】关键转折：
【合】单元收束/留下的尾巴：
单元爽点分布：
关键伏笔（埋设/回收）：
```

### Step 3：单元间衔接检查
- 每个单元结尾必须有 1-2 个"尾巴"延伸到下一单元
- 所有单元组合起来覆盖卷纲的全部节点
- 节奏起伏：避免连续 3 个单元都是高潮（会疲劳）
- 检查各单元的爽点密度是否均匀（不能前紧后松）

### Step 4：整卷节奏审视
- 绘制整卷情绪曲线图（横轴：章节，纵轴：情绪张力）
- 标注高潮点、低谷点、转折点
- 确认起承转合完整

## 产出文件
```
大纲/02-卷纲/第NN部/第NNN卷-剧情单元.md
```

## 质量闸门
- [ ] 单元数量在 3-6 个之间
- [ ] 每个单元有完整起承转合
- [ ] 单元间有衔接"尾巴"
- [ ] 节奏起伏合理（无连续高潮/连续低谷）
- [ ] 覆盖卷纲全部节点

## 故障恢复
| 问题 | 处理方式 |
|------|---------|
| 单元划分不合理 | 回 Step 1 重新划分，确保每单元有独立功能 |
| 衔接断裂 | 在单元末尾添加过渡事件或悬念 |
