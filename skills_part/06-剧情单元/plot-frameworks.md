# 情节框架模板（Plot Frameworks）

常见的故事框架模板，可用于规划整个故事或单卷情节。

---

## 一、三幕式结构

**适用**：大多数故事

### 第一幕：设置（25%）
- 第1章：介绍主角现状
- 第2章：激励事件（打破现状）
- 第3章：主角决定行动

### 第二幕：对抗（50%）
- 第4-5章：新世界/新挑战
- 第6章：中点转折
- 第7-8章：困难升级
- 第9章：看似失败（最低谷）

### 第三幕：结局（25%）
- 第10章：最终对决
- 第11章：结局

## 三、悬疑结构

**适用**：侦探/推理/惊悚

### 第一幕：谜题出现
- 发现案件
- 侦探接手
- 初步线索

### 第二幕：调查深入
- 嫌疑人逐一排查
- 新线索/新案件
- 侦探陷入危险

### 第三幕：真相揭示
- 重大反转
- 最终对决
- 真相 + 余波

---

## 四、言情结构

**适用**：爱情题材

### 第一幕：相遇
- 主角A的现状
- 主角B的现状
- 相遇（第一印象不佳）

### 第二幕：发展
- 被迫相处，了解对方
- 吸引力增强
- 误解/障碍出现
- 关系破裂

### 第三幕：和解
- 意识到真爱
- 克服障碍
- 在一起

---

## 五、多线叙事结构

**适用**：复杂剧情/多主角

### 交叉模式
```
第1章：主角A故事
第2章：主角B故事
第3章：主角A推进
第4章：主角B推进
第5章：线索交汇
...
```

### 时间线模式
```
第1章：现在
第2章：过去（5年前）
第3章：现在（+1天）
第4章：过去（+1月）
...
```

### 收敛原则
- 各线最终必须交汇
- 早期看似无关的事件后来有关联
- 收敛时产生"原来如此"的效果
