## 章节节奏控制

### 长短句交替
句子长度决定阅读速度。短句快，长句慢。

**动作场景 — 短句为主：** 他侧身。刀锋擦着鼻尖过去。左脚蹬地，身体旋转，刀尖刺出。
**思考或描写 — 长句为主：** 她坐在窗边，忽然想起小时候母亲也是这样站在阳台上目送她上学，那时她觉得母亲的目光是理所当然的东西。

**操作规则：**
- 连续三句长度相同就必须打破
- 动作段落：句子控制在 10 字以内
- 转折时刻：用一个极短句制造停顿（"他愣住了。"）

### 段落呼吸
段落是读者的呼吸节奏。短急促，长平缓。

- **紧张场景：** 一段一两句话
- **缓和场景：** 一段五六句话
- **转折爆发：** 长段落中突然插入一个单句段落

### 信息密度波浪
高密度 → 低密度 → 高密度 → 低密度

**操作要点：**
- 一段高密度后必须跟一段低密度让读者消化
- 连续三段高密度 = 读者疲劳
- 连续三段低密度 = 读者无聊
- 每章应有 2-3 个密度波浪

### 节奏模式参考

| 题材 | 节奏模式 |
|------|---------|
| 悬疑/动作 | 紧张 → 短暂缓解 → 更紧张 → 高潮 → 悬念结尾 |
| 言情 | 轻松互动 → 情感升温 → 误会阻碍 → 真相告白 → 新悬念 |
| 奇幻/玄幻 | 修炼铺垫 → 危机降临 → 战斗突破 → 战后消化 → 新挑战 |

### 全章节奏检查法
1. 标记每段的"速度"（快/中/慢）
2. 画一条节奏曲线
3. 如果曲线是直线（全程匀速），需要调整

## 连贯性保证

### 写前必读
1. 阅读大纲中所有已完成章节的摘要
2. 读取上一章，了解当前悬念和情绪落点
3. 检查人物状态：位置、情绪、关系、已知信息

### 人物状态跟踪
- **位置** — 人在哪里，怎么到的
- **情绪** — 上一章结尾的心情是否延续
- **关系** — 和其他角色的关系变化
- **能力** — 是否获得了新技能、新信息

### 悬念线延续
- 每章至少回应一个旧悬念（哪怕是部分回应）
- 每章至少提出一个新悬念或升级现有悬念

### 一致性检查清单
- [ ] 人物行为符合其性格设定
- [ ] 前后伏笔有呼应，逻辑闭环完整
- [ ] 时间线连贯，没有跳跃错误
- [ ] 人物不会"忘记"自己已知的信息

## 章节长度与内容密度

| 类型 | 字数 | 核心事件 | 场景数 |
|------|------|---------|-------|
| 短章节 | 2000-3000 | 1 个 | 1-2 |
| 标准章节 | 3000-5000 | 2-3 个 | 2-4 |
| 长章节 | 5000-7000 | 3-4 个 | 3-5 |

**原则：** 每章至少包含一个不可删除的核心事件。3000-5000 字是默认目标。

## 类型特定检查

### 悬疑/犯罪
- [ ] 有新谜题提出
- [ ] 逻辑无漏洞
- [ ] 线索公平性：读者理论上可以提前猜到真相

### 言情/都市
- [ ] 关系有进展（不能原地踏步五章）
- [ ] 有情感张力（暧昧/误会/心动至少占一种）
- [ ] 甜虐比例根据剧情阶段调整

### 奇幻/科幻
- [ ] 世界观前后一致
- [ ] 设定不破坏（不能为了方便临时加设定）
- [ ] 力量体系有明确边界

### 动作类
- [ ] 动作场面清晰，读者能想象空间位置
- [ ] 每场动作有不同亮点
- [ ] 动作之间有情感 stakes

## 章节写作检查清单

### 开头检查（最关键）
- [ ] 前 20% 是否极其吸引人？
- [ ] 是否在第一段就建立冲突或紧张？
- [ ] 是否避免了所有致命错误？（天气/日常/回顾等）

### 内容检查
- [ ] 本章推进主线或深化人物？
- [ ] 对话推动情节或揭示人物？
- [ ] 结尾留下悬念钩子？

### 展示而非讲述
| 讲述（避免） | 展示（使用） |
|-------------|-------------|
| 他很愤怒 | 他握紧拳头，指节发白 |
| 她很美丽 | 他凝视着她，忘记说话 |
| 他很紧张 | 他反复调整领带 |
| 她很伤心 | 她低头搅咖啡，勺子停了很久 |

### 开头自测
如果以下回答"否"，必须重写：
1. 读者读前三段后会继续读吗？
2. 开头有冲突或危机吗？
3. 开头有意外或转折吗？

## 语言质量检查

### AI 写作痕迹清除
**高频 AI 词汇（出现一个改一个）：**
- "此外""然而""值得注意的是""需要强调的是"
- "彰显""诠释""赋以"
- "不禁""油然而生""心潮澎湃"

**禁止无意义"不是xxx"句式：**
- ❌ "一声巨响撞进耳膜，不是雷声，比雷声更低沉"
- ✅ "一声巨响撞进耳膜，那声音比雷声更低沉"

### "的"字密度控制
- 一句话里"的"不超过两个
- 修饰结构能简化就简化

### 用词精确
- 删除模糊词："一些""大概""似乎"（除非刻意）
- 用具体词替代抽象词："天气不好"→"闷热，空气黏在皮肤上"
- 动词优于形容词

## 质量评分

交付前为每章打分，客观评估。

| 维度 | 评分 | 说明 |
|-----|------|------|
| 开头吸引力 | /10 | 前 3 段抓住读者？ |
| 情节推进 | /10 | 推进主线？ |
| 人物塑造 | /10 | 行为一致且有深度？ |
| 对话质量 | /10 | 自然且推动情节？ |
| 悬念设置 | /10 | 结尾钩子有效？ |
| 节奏控制 | /10 | 张弛有度？ |
| 展示非讲述 | /10 | 用行动而非陈述？ |
| 语言质量 | /10 | 无 AI 痕迹？ |
| **总分** | **/80** | **>60 可交付，>70 优秀** |

**使用方法：** 每一项对照检查清单打分。低于 6 分必须修改。总分低于 60 → 整章大改。
